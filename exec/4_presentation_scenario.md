# 시연 시나리오

본 문서는 **AL-MAENG** 서비스의 주요 기능을 사용자 흐름(User Flow)에 따라 시연하기 위한 상세 시나리오를 담고 있습니다.

---

| 순서 | 화면/기능 | 실행 동작 (클릭 위치 등) | 기대 결과 및 멘트 포인트 | 시연 이미지 |
|------|-----------|--------------------------|--------------------------|-------------|
| 1 | 회원가입 | 네이버 로그인 버튼 클릭 | 네이버 소셜 로그인 연동 확인 | ![1](./images/01_signup.png) |
| 2 | 정보 입력 | 이름(김싸피), 출생연도(2000), 성별(여) 입력 | 유저 기본 메타데이터 수집 | ![2](./images/02_information.png) |
| 3 | 취향 선택 | 소설/시/희곡(SF, 미스터리), 경제 장르 선택 | 초기 큐레이션을 위한 장르 태깅 | ![3](./images/03_genre_taste.png) |
| 4 | 홈 - 배너 | 상단 이벤트 배너 클릭 | 배너 연결 페이지(영상 기반 추천)로 이동 | ![4-1](./images/04-1_banner.png) · ![4-2](./images/04-2_result.png) |
| 5 | 홈 - 맞춤 추천 | 추천 섹션 새로고침 버튼 3~4회 클릭 | 선호 장르 기반 도서 리스트 실시간 변경 확인 | ![5](./images/05_recommendation.png) |
| 6 | 홈 - 랭킹 | 완독순 / 찜한순 / 조회순 탭 전환 | 유저 활동 기반 도서 랭킹 보드 확인 | ![6](./images/06_ranking.png) |

## [Phase 4] 보관함 · 마이페이지 (기존 유저)

*Phase 3까지 진행한 계정에서 로그아웃 후, **티켓·완독·리포트 데이터가 충분히 쌓인 기존(시연용) 계정**으로 로그인하여 시연합니다.*

| 순서 | 화면/기능 | 실행 동작 (클릭 위치 등) | 기대 결과 및 멘트 포인트 | 시연 이미지 |
|------|-----------|--------------------------|--------------------------|-------------|
| 18 | 로그아웃 및 로그인 | 로그아웃 후 시연용 **구글 계정**으로 다시 로그인 | 헤비 유저 데이터(다량의 티켓·기록)로 Phase 4 시연 준비 | ![18](./images/18_login.png) |
| 19 | 티켓 갤러리 | 「나의 티켓」 메뉴 진입 | 티켓 갤러리 뷰 확인 | ![19](./images/19_user_gallery.png) |
| 20 | 티켓 바인더 | 바인더 탭 이동 후 **장르별 필터** 클릭 | 전체 티켓의 정리·장르 분류 UX 확인 | ![20](./images/20_user_binder.png) |
| 21 | 마이페이지 | 마이페이지 메인 화면 둘러보기 | 프로필·요약 정보 등 마이페이지 구조 확인 | ![21](./images/21_user_mypage.png) |
| 22 | 티어 | 마이페이지 상단 **티어** 영역·아이콘 확인 | 완독 수에 따른 유저 등급(티어) 노출 | ![22](./images/22_user_tier.png) |
| 23 | 취향 리포트 | 마이페이지에서 **독서 리포트** 확인 | 원형 및 레이더 차트로 취향 시각화 | ![23](./images/23_user_reports.png) |
